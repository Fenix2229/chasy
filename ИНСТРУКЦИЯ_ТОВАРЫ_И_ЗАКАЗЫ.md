## ЧАСТЬ 1: ЗАГРУЗКА ТОВАРОВ

### Способ 1️⃣: Через админ-панель (самый простой)

#### Шаг 1: Вход в админку
```
Адрес: https://komandirskie.su/admin
Пароль: указанный в файле .env (ADMIN_PASSWORD)
```

#### Шаг 2: Добавить один товар
1. Нажмите **"Добавить товар"**
2. Заполните форму:
   - **Название**: "Командирские 650539"
   - **Артикул**: "АРТ-001" (опционально)
   - **URL-адрес (slug)**: "komandirskie-650539"
   - **Категория**: выберите из списка
   - **Описание**: полное описание часов
   - **Цена**: 7990
   - **Старая цена**: 8990 (если есть скидка)
   - **Количество на складе**: 10
   - **Изображение**: загрузите фото
   - **Избранный товар**: отметьте если нужно
   - **Активный**: обязательно отметьте
3. Нажмите **"Сохранить"**

### Способ 2️⃣: Массовый импорт товаров через API

#### Вариант A: Через PowerShell (Windows)

Создайте файл `import_products.ps1`:

```powershell
# Замените URL и данные на свои
$url = "https://komandirskie.su/api/import/products"

$products = @(
    @{
        name = "Командирские 650539"
        slug = "komandirskie-650539"
        article = "АРТ-001"
        category_id = 1
        price = 7990
        old_price = 8990
        stock = 10
        description = "Классические военные часы"
        image = "/images/products/watch-komandirskie-1.svg"
        is_active = $true
        is_featured = $true
    },
    @{
        name = "Амфибия 420059"
        slug = "amfibiya-420059"
        article = "АРТ-002"
        category_id = 2
        price = 8990
        old_price = 9990
        stock = 5
        description = "Водоустойчивые часы"
        image = "/images/products/watch-amfibiya-1.svg"
        is_active = $true
        is_featured = $false
    }
)

$body = @{
    products = $products
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Uri $url `
    -Method Post `
    -ContentType "application/json" `
    -Body $body | ConvertTo-Json
```

Запустите:
```powershell
powershell -ExecutionPolicy Bypass -File import_products.ps1
```

### Способ 2️⃣: Скачать все заказы в JSON

```
https://komandirskie.su/api/export/orders
```

Откроется JSON с ALL заказами. Нажмите **Ctrl+S** чтобы сохранить.

#### Скачать только новые заказы:
```
https://komandirskie.su/api/export/orders?status=pending
```

#### Статусы для фильтрации:
```
?status=pending         → новые заказы
?status=processing      → в обработке
?status=shipped         → отправлены
?status=delivered       → доставлены
?status=cancelled       → отменены
```

### Способ 3️⃣: Выгрузить в Excel через PowerShell

Создайте файл `export_orders.ps1`:

```powershell
# Скачать заказы в JSON
$orders = Invoke-RestMethod -Uri "https://komandirskie.su/api/export/orders?status=pending"

# Конвертировать в CSV для Excel
$orders.orders | Select-Object `
    @{N='ID';E={$_.id}}, `
    @{N='Клиент';E={$_.customer.name}}, `
    @{N='Телефон';E={$_.customer.phone}}, `
    @{N='Email';E={$_.customer.email}}, `
    @{N='Адрес';E={$_.shipping.address}}, `
    @{N='Сумма';E={$_.total}}, `
    @{N='Статус';E={$_.status}}, `
    @{N='Дата';E={$_.created_at}} | `
    Export-Csv -Path "orders_$(Get-Date -Format 'yyyy-MM-dd').csv" `
    -NoTypeInformation -Encoding UTF8 -Delimiter ";"

Write-Host "Заказы экспортированы в CSV"
```

Запустите:
```powershell
powershell -ExecutionPolicy Bypass -File export_orders.ps1
```

```bash

  jq -r '.orders[] | [.id, .customer.name, .customer.phone, .total, .status, .created_at] | @csv' | \
  sed 's/"//g' > orders.csv
```

## ЧАСТЬ 3: ОБНОВЛЕНИЕ СТАТУСА ЗАКАЗА

### Через админ-панель:
1. Откройте заказ в админке
2. Нажмите на статус и выберите новый
3. Сохраните

### Через API:

#### PowerShell:
```powershell
$orderId = "ORD-001"

$body = @{
    status = "shipped"
    paymentStatus = "paid"
} | ConvertTo-Json

Invoke-RestMethod -Uri "https://komandirskie.su/api/orders/$orderId/status" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body
```

#### curl:
```bash
curl -X POST https://komandirskie.su/api/orders/ORD-001/status \
  -H "Content-Type: application/json" \
  -d '{"status": "shipped", "paymentStatus": "paid"}'
```

#### Возможные статусы:
```
pending      → новый
processing   → в обработке
shipped      → отправлен
delivered    → доставлен
cancelled    → отменен
```

## ЧАСТЬ 6: РЕШЕНИЕ ПРОБЛЕМ

### Ошибка: "Cannot POST /api/import/products"
**Решение:** Проверьте URL сайта. Убедитесь, что правильно указали домен.

### Товар не отображается на сайте
**Решение:** 
- Проверьте что `is_active: true`
- Проверьте что `category_id` существует
- Проверьте что `stock > 0`

### Заказ не сохранился
**Решение:** 
- Проверьте что все поля заполнены
- Проверьте что товар с указанным ID существует
- Проверьте количество товара на складе

### Изображение товара не загружается
**Решение:**
- Убедитесь что путь правильный: `/images/products/имя.jpg`
- Проверьте что файл загружен в нужную папку
- Используйте формат JPG или PNG
